# Desktop AI Pet · 界面设计方案

> 基于《桌面 AI 宠物系统设计文档》的 UI 设计提案。目标：**美观、易用、轻量**，让"它真的活在我的桌面上"这件事在界面层面也被感受到。
> 配套高保真可交互原型：`desktop-ai-pet-ui.html`（点击左侧导航切换 概览 / 对话 / 宠物图鉴 / 设置，右下角可呼出系统托盘）。

---

## 1. 设计原则（从文档提炼）

| 原则 | 文档依据 | 设计落点 |
|---|---|---|
| **轻量、非后台** | §19"主界面不要做成传统后台系统" | 不用侧边大菜单+表格的后台风；用卡片化、圆润、留白的控制面板 |
| **本地优先 / 可离线** | §5.3、§26.3、§26.4 | 密钥本地保存提示、断网仍活动的状态提示、AI 可跳过引导 |
| **身体与灵魂解耦** | §5、§26 | 界面区分"行为开关"（本地）与"AI 配置"（灵魂），逻辑可见 |
| **生命感可视化** | §15 情绪系统 | 概览页用 5 条情绪条 + 心情气泡呈现"活物"状态 |
| **一键可达** | §20 系统托盘 | 托盘 7 项高频操作，无需打开主窗口 |

## 2. 设计语言（Design Language）

### 2.1 色彩
- **主色 `--primary #FF7A59` 暖珊瑚**：友好、有温度，契合"桌宠"而非"工具"。
- **AI 辅助色 `--ai #6C8CFF` 柔蓝**：专用于 AI / 对话 / 技术类元素，与"身体(暖)"形成冷暖语义区分。
- **中性暖底 `#FFF7F2`**：奶油白背景，避免冷冰冰的后台灰。
- **情绪色板**：开心 `#FFC53D` / 难过 `#6C8CFF` / 生气 `#FF6B6B` / 惊讶 `#B47CFF` / 平静 `#34C77B`，统一用于心情与状态。

### 2.2 形状与阴影
- 圆角梯度：`--r-xl 28` 窗口 / `--r-lg 22` 卡片 / `--r-md 16` 控件 / `--r-sm 11` 小元素。整体"软、圆、亲"。
- 阴影分三层：1px 描边 + 柔投影，强调悬浮微交互（hover 抬起、点击回弹）。

### 2.3 字体与层级
- 中文优先字体栈：PingFang SC / 微软雅黑 / system-ui。
- 标题 21px / 区块 14px / 正文 13.5px / 辅助 11.5px，行高宽松，降低阅读压力。

### 2.3 微交互（符合用户习惯）
- 开关、卡片选中用**颜色填充+描边光圈**而非生硬高亮。
- 情绪条加载时**从 0 动画到目标值**，传达"正在感知"。
- 桌面预览里宠物**轻轻浮动（bob）**，即使静态界面也有"活物感"。
- 对话发送后先显示"正在思考…"再回复，符合 AI 异步特性，避免假即时。

## 3. 界面清单与功能映射

### 3.1 首次引导（Onboarding）— 对应 §25 体验起点
- 三步：选人格 → 连 AI（可跳过）→ 完成。
- 跳过强调"断网也能用"，打消用户对密钥的顾虑（§26.4）。
- 圆点进度 + 大图宠物，降低第一次启动的陌生感。

### 3.2 概览 Dashboard — 新增，承载"生命感"
- **宠物英雄卡**：头像（在线徽标）+ 名称 + 人格 + 当前心情气泡 + 快捷操作（聊天/召唤/暂停）。
- **桌面预览微场景**：一只宠物趴在窗口顶边，直接呈现核心卖点（§9、§14）。
- **情绪状态卡**：5 维（happiness / energy / curiosity / affection / boredom）可视化，落实 §15。
- **离线提示条**：强化"本地行为系统永远在线"（§26.3）。

### 3.3 对话 Chat — 对应 §16、§18
- 左右气泡区分你我，宠物气泡带人格标签。
- 底部输入 + 🎤（STT 可选）+ 发送；右上"语音播报"开关（TTS）。
- 顶部显示聆听状态与人格 chip，呼应"AI 按人格说话"。

### 3.4 宠物图鉴 Pets — 对应 §3、§20"更换宠物"
- 网格卡片：真实生成形象（奶糖、小狐）+ emoji 占位（猫/狗/龙/小恶魔/虚拟人），体现"人宠同一套 Pet Entity"。
- 类型筛选（全部/萌宠/虚拟人/原创），选中态用主色光圈 + "使用中"徽标。

### 3.5 设置 Settings — 对应 §6、§7、§19
- **AI 配置**：API Base URL / API Key（密码框）/ Model 下拉（DeepSeek·OpenAI·Gemini·Claude·Ollama…）+ 连接测试，落实"OpenAI Compatible、不写死"（§6）。
- **人格**：温柔型 / 务实型 卡片（含描述）+ 4 个维度滑块（warmth/practicality/initiative/talkativeness），对应 §7 的 Personality Profile。
- **行为开关**：自动活动 / 追踪鼠标 / 窗口互动 / 语音播报 / 登录自启——本地行为系统的可视化控制台（§19）。
- **外观**：大小、透明度、主题（浅色暖奶油 / 深色夜色 / 跟随系统）。

### 3.6 系统托盘 Tray — 对应 §20
- 右下角弹出：聊天 / 暂停 / 重新召唤 / 设置 / 更换宠物 / 隐藏 / 退出，7 项与文档完全一致。
- 主窗口"系统托盘"按钮一键预览，演示真实落地形态。

## 4. 与验收标准（§27）的对应

| # | 验收项 | 界面支撑 |
|---|---|---|
| 1–6 | 透明宠物/移动/拖动/鼠标反应/窗口停留/窗口互动 | 概览桌面预览 + 行为开关 + 托盘"召唤/隐藏" |
| 7 | 温柔/务实人格 | 设置人格卡片 + 引导选择 |
| 8 | 配置 OpenAI Compatible API | 设置 AI 配置区 + 连接测试 |
| 9 | 文本对话 | 对话页 |
| 10 | AI 触发情绪与动作 | 概览情绪条 + 心情气泡 + 对话人格标签 |
| 11 | AI 不可用仍运行 | 离线提示条 + 引导"可跳过" + 行为开关本地可控 |
| 12 | 托盘与退出 | 系统托盘菜单 |

## 5. 可继续深化的方向（留接口）
- **暗色主题**：变量已预设 `--text/--surface` 反向即可整套切换。
- **Live2D / Spine / VRM**：图鉴占位卡已为真实素材预留 `background-image` 接入点。
- **多宠物共存**：图鉴选中逻辑天然支持扩展为"同屏多只"。
- **自定义人格**：滑块当前为展示，下一步可改为可编辑并写入 Personality Profile。
