# 宠物样式改造调研：小黑点（dot）形态

> 目标：给现有桌宠新增第 4 种形态 `dot`——极简黑球 + 大白眼，参照开源项目 Emotion Ball 的表情驱动思路。
> 结论先行：**马斯克/xAI 名下没有开源的"小黑 dot"项目**，你记的那个形象大概率来自 Grok Companions（闭源）或 dot.com 域名梗。能合法借鉴的是社区的 Emotion Ball。

**2. "dot" 的梗来自域名，不是代码**
2026-09-30 OpenAI 发布全天候智能体 **Dots**，网友发现 **dot.com 早被 xAI 注册**，访问会跳转到 Grok 下载页，于是出现"马斯克提前抢域名恶搞对手"的话题。近几天的中文报道都在讲这件事——**这里没有任何开源仓库**，很可能是你记忆里"开源的小黑 dot"的混淆来源。

**3. 马斯克系真正的"极简小圆形象"= Grok Companions（闭源）**
xAI 从 2025-06 起在 Grok 里上线动画伴侣角色，走"简单几何体 + 实时程序化动画"路线，后续还加了 Ani、Rudi、以及以《异乡异客》主角命名的 Valentine。这套东西是**私有产品，没有源码**，只能借鉴视觉语言，不能拿素材。

一句话：想要"小黑 dot"，我们**自己用 Canvas 画一个**，比找现成素材更契合本项目"零外部素材"的现有架构（`src/pet/PetRenderer.ts:1` 注释已写明这条约束）。

## 三、现有代码事实（改动前必读）

渲染链路：`PetBrain`（FSM/情绪/窗口）→ `PetAnimation`（把状态映射成每帧参数）→ `PetRenderer`（纯 Canvas 画）。

- 形态类型定义了**两次**：`src/pet/PetRenderer.ts:2` 和 `src/lib/tauri.ts:103`（`'cat' | 'bunny' | 'fox'`），加新形态两处都要改。
- 调色板 `PAL` 是 `Record<Species, Palette>`（`PetRenderer.ts:54`）——TS 穷尽性检查会**强制**我们补 dot 配色，漏了直接编译不过。
- 三处几何分支默认"非兔子就是猫/狐"，dot 必须显式排除，否则会画出猫耳和胡须：
  - `PetRenderer.ts:235` 尾巴（兔子画圆球尾，其余画摆尾）
  - `PetRenderer.ts:290` 耳朵（bunny 长耳 / 猫狐三角耳）
  - `PetRenderer.ts:514` 胡须（`species !== 'bunny'` 就画）
- 眼睛主色硬编码深棕 `#3B2B20`（`PetRenderer.ts:346`、`355`、`365` 等），黑球上必须换成白底黑瞳。
- 已有的表情基元够用：`EyeState` 8 种（open/happy/closed/surprised/angry/sad/sleepy/wink）、`MouthKind` 6 种（smile/cat/open/o/frown/flat）、`blush`、`talk`、瞳孔偏移 `eyeDX/eyeDY`（跟随鼠标，`PetBrain.ts:397`）、落地挤压 `squash`（`PetRenderer.ts:85`）、粒子 5 种（zzz/heart/sweat/note/sparkle）。
- 姿态 7 种：`stand/walk/sit/lay/sleep/hang/jump`，由 `PetAnimation.poseFor()`（`PetAnimation.ts:37`）从 FSM 状态映射。
- 其它 species 触点：`src/ai/Personality.ts:29`（中文名 switch，同样受穷尽性约束）、`src/settings/SettingsApp.vue:204`（图鉴卡片）、`src/chat/ChatApp.vue:41`/`:48`（聊天头像与 emoji）、`src/pet/PetBrain.ts:937`（托盘变身轮换数组）、`src/lib/tauri.ts:167`（`EmotionPayload.species`）。
- **现存小 bug 提醒**：`PetBrain.ts:946` 的变身台词是三元链 `cat ? … : bunny ? … : '狐狸模式，启动。'`，直接加 dot 会出现"变成黑点却说狐狸模式"。这一处必须显式改成 switch。
- Rust 侧 grep `species` 零命中——形态只存在于 TS 层，`src-tauri` 不用动。

## 四、dot 形态设计规格

### 4.1 形体

单球，不分头身（现有的"身 44×36 + 头 40×37"两段结构对 dot 拆掉）：

- 半径 `R = 34 * u`，圆心 `cy = feetY - R * (1 - 0.55 * squash)`；贴地时压扁，跳起时拉长。
- 无耳、无尾、无胡须、无四肢。
- 呼吸：`scaleY = 1 + 0.03 * sin(breathe)`，配合 `scaleX` 反向（体积守恒），比现在的椭圆呼吸更有"活物"感。
- 形变语言（squash & stretch，dot 的全部表演都靠它）：
  - `stand` 微幅上下浮动 + 轻微左右扭动（`tailPhase` 复用做 bodySway）
  - `walk` 弹跳式前进：垂直 `abs(sin(walkPhase))`，落地瞬间 squash 峰值 0.35
  - `sit` 压扁成 `rx=1.15R, ry=0.82R`
  - `lay` / `sleep` 摊成饼 `rx=1.35R, ry=0.55R`，眼睛闭合成两条弧
  - `hang`（被拎起）拉成水滴：上部窄、下部坠，眼睛惊讶
  - `jump` 竖向拉长 `rx=0.86R, ry=1.18R`

### 4.2 配色

黑球不等于纯黑，需要一点冷暖分层才不显"死"：

```
body        #16181D   // 主体
bodyHi      #2B3038   // 顶部高光椭圆（alpha 0.55）
rim         rgba(255,255,255,0.10)  // 1px 描边高光，防止在深色窗口/任务栏上糊掉
eyeWhite    #FFFFFF
pupil       #0C0D10
blush       #FF8AA0
mouth       #FFFFFF   // 白嘴（黑底上比深棕更清楚）
```

`rim` 很关键：本项目宠物窗口是透明的（`PetApp.vue:97` `background: transparent`），纯黑轮廓落在白色网页或浅色桌面上没问题，落在深色壁纸上会消失。

### 4.3 眼睛

dot 的辨识度 90% 在眼睛上：

- 白眼白为竖向椭圆，`rx = 8.5 * u`、`ry = 10.5 * u`，间距 `±13 * u`，中心 `y = -2 * u`（相对球心）。
- 瞳孔 `r = 3.6 * u`，位置 = 眼白中心 + `(eyeDX * 3.4, eyeDY * 2.8) * u`，直接复用现有的鼠标跟随数据。
- **眼珠延迟跟随**：在 `PetAnimation.update` 里给瞳孔加一阶低通（`lag += (target - lag) * min(1, dt * 6)`），比身体反应慢半拍是"呆萌"的核心；现在 `headTilt` 已经是这个写法（`PetAnimation.ts:143`），照搬即可。
- 眨眼：复用 `eyeClosed`，但 dot 的眨眼应该是**眼白整体高度压扁**而不是画一条线，闭眼到底时留 2px 弧。

### 4.4 表情映射表

现有 `ExprKind` × `PoseKind` 足够驱动，不新增枚举。dot 的表情表（把 Emotion Ball 的"一个 id 一张脸"落到我们这套参数上）：

| 场景（state / expr） | 眼型 | 瞳孔 | 嘴 | 形变/粒子 |
| --- | --- | --- | --- | --- |
| 平时 IDLE / neutral | 标准竖椭圆 | 居中，跟随鼠标 | 短平线（flat） | 呼吸 |
| 走路 WALK | 标准 | 前视 | flat | 弹跳 |
| 被摸 / happy | 上弯弧（happy） | 隐藏 | smile | blush 1.0，heart 粒子 |
| 玩 / PLAY | wink 交替 | 单眼隐藏 | smile | note 粒子，左右扭动加快 |
| 惊讶 DRAG / FALL / surprised | 大圆（surprised） | 缩小 0.6，居中 | o | 拉成水滴，sweat |
| 生气 ANGRY / angry | 压扁竖椭圆 + 倒眉 | 上移 | flat | 高频微抖 |
| 难过 sad | 下弯 + 内低外高 | 下移 | frown | 泪（复用 sweat 形状改蓝白） |
| 犯困 sleepy | 半闭（sleepy） | 下移 | flat | 呼吸变慢 |
| 睡觉 SLEEP | 两条弧 closed | 隐藏 | flat | zzz |
| 关切 concern | sad 眼但嘴角不撇 | 居中偏上 | flat | 无 |
| 说话 talking | 标准 | 跟随 | open（`talk` 驱动高度） | 每 3 帧切换张嘴幅度 |
| 变身瞬间 | 大圆 | 居中 | o | sparkle 8 颗 |

后续想扩到 32 种（跟 Emotion Ball 打平），成本很低：`EyeState` 加 `shiny`（星星眼）、`dizzy`（螺旋）、`flatline`（一横），`MouthKind` 加 `grin`（大口弧形）、`wavy`（波浪嘴）即可，全部是 Canvas 弧线，不引外部素材。

## 六、风险与取舍

- **黑底白眼 vs 现有暖色系不搭**：现有 UI（气泡、菜单、设置卡片）是奶油橙调（`#FFB05C`、`#ff7a59`），一颗墨黑球放上去会显得"外来"。要么给 dot 配一层柔和外发光，要么接受这种反差——建议先按原样出一版看效果再决定。
- **透明窗口的描边问题**：见 4.2 的 `rim`，不加在深色桌面上会看不见边界。
- **`species` 两处重复定义**是隐患，但本次不合并（属于额外重构）；若你希望顺手收敛，把 `PetRenderer.ts` 改成从 `lib/tauri.ts` re-export 即可，改法独立于样式。
- **许可证**：Emotion Ball 是自定义许可、utsuwa 是 AGPL-3.0。本次只借鉴"状态 id → 表情"的接口思路与视觉语言，**不复制任何源码或素材**。
- 按项目既有约定，新增的变身/切换提示一律走应用内组件，不用 `alert`/`confirm`。
